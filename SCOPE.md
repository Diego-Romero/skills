# Scope

This repo is the set of skills I use. It is curated, not a registry.

## The bar

An issue stays open only if it clears both parts:

1. **Observed failure.** It describes something that went wrong in a real run: what you ran, what the skill did, what you expected. A hypothetical improvement ("it would be better if...") does not clear this part.
2. **Fits the method.** It is not a config option or a tweak for one person's workflow. Those belong in your own `AGENTS.md` or in a fork.

Size does not matter: a one-word fix and a rewrite face the same bar.

## New skills

New skills are not accepted from outside for now. If the behaviour can be composed from existing skills, it does not get a new one.

## Questions

Questions and discussion go to GitHub Discussions, once enabled.
